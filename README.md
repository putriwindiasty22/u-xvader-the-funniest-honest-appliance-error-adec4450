An entry for the [make.fun bounty "The Funniest Honest Appliance Error"](https://make.fun/c/u-xvader-the-funniest-honest-appliance-error-adec4450): one line, at most 200 characters — the funniest honest error message an appliance could show.

## The entry

> WARNING: door opened 47 times today. There is still no food in here, and I am now warmer than the milk.

(103 characters.)

A fridge, in its own flat, put-upon voice, reporting the plain truth: the door keeps opening, nothing new is inside, and the honest consequence of all that opening is that the fridge itself is now warmer than the milk it is supposed to chill. The laugh comes from the fault, not from a pun.

## How to run

Requires Node 22.18 or later.

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt`.
